# 文档索引

本目录维护当前 STM32F407 固件的使用说明。树莓派端工程不在本仓库内；
历史迁移提示词不应作为当前配置或协议依据。

## 建议阅读顺序

1. [项目首页](../README.md)：项目范围、当前能力和安全提醒。
2. [工程结构与运行流程](architecture.md)：各目录职责、任务调度和使能条件。
3. [硬件连接](hardware.md)：引脚、DMA、电源与接口限制。
4. [构建与测试](build-and-test.md)：工具链、两种应用模式、测试和烧录。
5. [上板与联调](bringup.md)：分阶段检查、OLED 状态和已知限制。

## 模块文档

- [树莓派视觉通信](../Modules/RaspberryPiVision/README.md)：当前 V1/V2 格式、
  黄金帧、USB 接收队列、启动确认与超时。
- [单轴陀螺仪](../Modules/SingleAxisGyro/README.md)：协议适配、量程说明和
  独立测试模式。

模块文档保留在对应源码目录旁，避免在多个位置重复维护协议和测试说明。
字段、状态位和黄金向量分别以模块头文件、解析实现及主机测试交叉核对。

## 目录整理说明

- `HARDWARE_MIGRATION.md` 更新并迁至 [hardware.md](hardware.md)。
- 两份 `RASPBERRY_PI_*_PROMPT.md` 移至 [archive/](archive/README.md)，
  原文保留用于追溯，不再作为新开发入口。
- 源码、依赖库、工具脚本、CubeMX 和 CMake 路径不变。
- 构建产物仍在已忽略的 `build/` 中，不提交二进制、日志或本机缓存。
- 日期化验证记录只代表对应源码和环境，不代表当前硬件状态。

新增当前文档放在 `docs/`，纯历史资料放在 `docs/archive/`。涉及运行行为
变化时同步更新相应当前文档；不要仅在历史提示词中追加新要求。
